# Market Intelligence Dashboard v0.2

기존 HTML/CSS/Vanilla JavaScript UI를 유지한 로컬 일별 시장 데이터 대시보드입니다.

공개 저장소에는 코드와 실행 문서만 포함합니다. 실제 시세 `data/markets.json`과 제공받은 KRX 명세서(`Spec.docx`, `Spec-2.docx`)는 저작권·재배포 조건 때문에 제외했습니다. 최초 실행 시 아래 수집 명령으로 로컬 데이터를 생성하세요. 데이터가 없을 때도 DEMO 모드를 사용할 수 있습니다. 설치·빌드·DB·백엔드 앱이 필요하지 않습니다. Python 3.9 이상과 시스템 `curl`을 사용합니다(macOS 기본 제공). HTTPS 인증서 검증을 유지합니다.

## 실행 / 수동 갱신

프로젝트 폴더에서 실행하세요.

```sh
# 작업 디렉터리가 상위 폴더인 경우
cd market-intelligence-preview

# 수집 및 기술 지표 계산
python3 scripts/collect_data.py

# 로컬 정적 파일 서버 (별도 터미널)
python3 -m http.server 3000 --bind 127.0.0.1
```

[http://localhost:3000](http://localhost:3000)에 접속합니다. 갱신 명령 실행 후 화면의 **JSON 다시 읽기**를 누르세요. 이 버튼은 공급자 호출 없이 로컬 파일만 읽습니다. 포트 충돌 시 3001을 지정하세요. 종료는 Ctrl+C입니다.

- 기본 **REAL DATA**: 실제 종가·기술 지표. 예측/뉴스/모델 성능은 미연결 상태입니다.
- **DEMO**: 기존 고정 샘플과 모든 원래 상호작용을 유지합니다. 실제 데이터와 섞이지 않습니다.
- `file://`로 직접 열면 DEMO는 작동하지만 REAL DATA는 로컬 서버가 필요합니다.
- 데이터 수집은 수동입니다. 자동 주기 갱신이나 거래·투자 추천은 없습니다.

## 데이터 출처와 현재 제공 범위

| 시장 | 수집원 | 인증 / 상태 |
| --- | --- | --- |
| S&P 500 | [S&P Dow Jones Indices LLC via FRED, SP500](https://fred.stlouisfed.org/series/SP500) | CSV, 키 불필요 · 실제 수집 확인 |
| NASDAQ 100 | [Nasdaq, Inc. via FRED, NASDAQ100](https://fred.stlouisfed.org/series/NASDAQ100) | CSV, 키 불필요 · 실제 수집 확인 |
| KOSPI | [KRX OPEN API](https://openapi.krx.co.kr/contents/OPP/MAIN/main/index.cmd), `idx/kospi_dd_trd` | 인증키·서비스 승인 필요 |
| KOSDAQ | KRX OPEN API, `idx/kosdaq_dd_trd` | 인증키·서비스 승인 필요 |

미국 두 시장은 약 800일의 달력 구간에서 일별 종가를 가져옵니다. 장중 실시간 데이터가 아니며 FRED 게시 지연이 있을 수 있습니다. 주가 지수의 포인트 값이며 통화 환산이나 ETF 대체값이 아닙니다. 날짜는 원 출처의 관측 거래일입니다. 수집 시각은 UTC로 저장하고 화면에는 KST로 표시합니다. 관측일이 4일 이상 경과하면 휴장일 미반영 주의를 표시합니다.

KRX는 [공식 이용 절차](https://openapi.krx.co.kr/contents/OPP/INFO/OPPINFO003.jsp)에 따라 인증키 발급과 **KOSPI/KOSDAQ 각 API 활용 승인**이 필요합니다. 승인받은 키를 터미널 환경변수 `KRX_API_KEY`에 설정한 후 동일한 수집 명령을 실행하세요. 키를 HTML·JSON·소스에 넣지 마세요. 최초에는 시장별 약 420일(평일 약 300회)을 조회하고 이후 마지막 관측일 전 7일부터 재조회합니다. 동시 수집은 피하세요. KRX 어댑터는 오프라인 응답 파싱을 검사했고, 사용자 환경에서 두 API의 실제 종가 응답을 확인했습니다. 인증키는 각 실행 환경에서 별도로 설정해야 합니다. 제공자의 명세·사용량 한도를 확인한 후 실행하세요. 키가 없거나 제공자가 응답하지 않으면 임의값 대신 이용 불가를 표시합니다.

## 계산 방식

모든 지표는 로컬 Python에서 **유효 종가만** 사용합니다. 결측·휴장일 보간이나 임의 대체는 하지 않습니다. 일부 거래일이 누락되면 관측 간격이 달라질 수 있습니다.

- SMA 20/50/200: 최근 N개 종가의 단순 평균
- RSI 14: 초기 14개 수익 차이 평균 후 Wilder 평활. 상승·하락 모두 0이면 50
- MACD: EMA 12 − EMA 26, Signal EMA 9, Histogram MACD − Signal. EMA는 최초 N개 값의 SMA로 초기화
- 20일 수익률: `(종가 / 20관측일 전 종가 - 1) × 100`, 배당 미포함
- 실현변동성: 최근 20개 로그 수익률의 표본 표준편차(ddof=1) × √252 × 100
- 이력 부족은 null / 이용 불가입니다. 초기화 방식과 관측 이력에 따라 다른 서비스와 미세 차이가 날 수 있습니다.
- 상승/하락/혼조 표시는 SMA 20과 20일 수익률에 대한 단순 규칙이며 예측 확률이 아닙니다.

## 파일과 오류 처리

- `index.html`: 기존 UI·DEMO 데이터·탭 이벤트
- `real-data.js`: 로컬 JSON 로딩·실제 데이터 UI·차트 툴팁
- `scripts/providers.py`: 교체 가능한 FRED / KRX 어댑터
- `scripts/collect_data.py`: 검증·지표 계산·원자적 저장
- `data/markets.json`: 실제 시세 이력·지표·출처·시장별 기준일/수집시각/오류 상태
- `scripts/test_data.py`: 네트워크 없는 회귀 검사

제공자별 수집 실패는 다른 시장 갱신을 막지 않습니다. 이전 정상 이력이 있으면 값·이력·지표·정상 수집 시각을 유지하고 `stale` 및 오류를 기록합니다. 이전 이력이 없으면 `unavailable`입니다. JSON은 임시 파일 작성 완료 후 원자적으로 교체합니다. 기존 JSON이 깨져 있으면 덮어쓰지 않고 종료합니다. 날짜 역행·중복·미래일·유효하지 않은 수치·이력 급감·10일 초과 오래된 신규 응답은 거부합니다.

종료 코드: `0` 전체 성공 / `1` 하나 이상 실패(성공한 시장은 저장됨) / `2` 전체 작업 또는 저장 실패. 현재 KRX 키가 없으면 미국 수집 성공이어도 코드 1이 정상입니다. 화면의 파일 로딩 실패 시 같은 브라우저 세션에서 마지막으로 읽은 정상 JSON을 유지합니다. 새로고침 후 파일까지 없으면 이용 불가이며 DEMO로 자동 전환하지 않습니다.

python3 scripts/test_data.py

## KRX 요청 실패 진단

문서의 JSON 요청 예시에 맞춰 KRX 요청을 `POST` + `Content-Type: application/json` + `{"basDd":"YYYYMMDD"}`로 전송합니다. `AUTH_KEY`는 헤더에만 전달합니다. 업로드된 명세에는 HTTP 메서드가 명시되어 있지 않으므로 POST 전환만으로 오류 해결을 보장하지 않습니다.

키를 설정한 **같은 터미널**에서 먼저 하루만 진단하세요. 과거 이력을 수백 회 수집하지 않으며 기존 JSON을 변경하지 않습니다.

```sh
python3 scripts/collect_data.py --check-krx 2026-10-14
```

- `OK`: 해당 지수의 실제 종가 응답을 확인했습니다. 일반 수집 명령 실행 후 JSON 다시 읽기를 누르세요.
- `HTTP 401`: 키 유효성을 확인하세요.
- `HTTP 403`: 인증키 승인과 해당 API 활용 승인 및 접근 정책을 확인하세요.
- `HTTP 400 / 405`: 요청 형식 또는 HTTP 메서드를 확인하세요.
- `HTTP 429`: 요청 한도 초과입니다. 잠시 후 재시도하세요.
- `HTTP 000` 및 curl 5/6/28/56: DNS·프록시·연결·응답 수신 문제일 수 있습니다. 인증 실패로 단정하지 마세요.
- 데이터 없음: 휴장일 또는 아직 게시되지 않은 날짜인지 확인하세요.

키가 승인됐더라도 사용자 터미널에서 설정한 환경변수는 Codex 실행 프로세스로 자동 전달되지 않습니다. 진단 오류를 공유할 때 키는 포함하지 마세요.

### 일부 시장만 다시 수집

시간 초과로 KOSPI만 실패했다면, 키를 설정했던 같은 터미널에서 실행하세요.

```sh
python3 scripts/collect_data.py --markets ks
```

선택하지 않은 시장은 요청하지 않고, 기존 값·이력·상태·수집 시각을 그대로 보존합니다. 시장 코드는 `sp`(S&P 500), `nq`(NASDAQ 100), `ks`(KOSPI), `kq`(KOSDAQ)입니다. 최초 수집 도중 실패한 시장은 아직 저장된 완전한 이력이 없으므로 해당 시장 이력을 처음부터 다시 요청합니다.

일시적인 DNS·연결·응답 시간 초과와 HTTP 500/502/503/504는 요청당 최대 3회 시도합니다(1초·2초 대기). 인증/권한 오류(401/403), 한도 초과(429)는 자동 재시도하지 않습니다. 반복 실패 시 마지막 정상 데이터는 유지하며, 오류에 실패 기준일을 포함합니다.
